# Support

## Where to ask

- Usage and setup questions: GitHub Discussions.
- Reproducible public-client bugs: GitHub Issues using the bug template.
- Feature proposals: GitHub Issues using the feature template.
- Account, billing, payment, quota, or private usage questions: use the support channel in the 4YI console.
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md).

## Before sharing diagnostics

Remove API keys, CLI tokens, account and organization identifiers, prompts, generated content, private file paths, and complete configuration files. Prefer the output of `4yi doctor`; it is designed not to print the stored token.

The public issue tracker cannot resolve private account or billing cases.
